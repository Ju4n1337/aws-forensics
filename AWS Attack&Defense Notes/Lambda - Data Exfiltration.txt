4.2) Get the policies attached to each function
Run the following code in the AttackBox

//CODE BEGINS
FUNCTIONS="list-images download-images"

for f in $FUNCTIONS ; do
    ROLE=`aws lambda get-function --function-name $f --query Configuration.Role --output text | awk -F\/ '{print $NF}'`
    echo "$f has $ROLE with these managed policies:"
    aws iam list-attached-role-policies --role-name $ROLE
    for p in `aws iam list-role-policies  --role-name $ROLE --query PolicyNames --output text` ; do
        echo "$ROLE for $f has inline policy $p:"
        aws iam get-role-policy --role-name $ROLE --policy-name $p
    done
done
//CODE END

Note: The above commands will iterate the list of  functions, and for each, extract the functions execution role in the variable ROLE. It then lists the attached policies for the role, and any inline policies for the role.

4.3) Attack list_images function
Use the following code to return the files from the function in the attackbox

def lambda_handler(event, context):

  command = f"aws s3 ls s3://{os.environ['list-images']}/{event['prefix']}"
  files = os.popen(command).read()
  return(files)

Note: When passed the following JSON, this function will return a list of objects in the IMAGE_BUCKET, then run whatever else we add to the end of the command.
