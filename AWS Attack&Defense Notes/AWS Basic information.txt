API Access Keys
There are two types of access keys: Long Term and Temporary Session keys.

Long-term access keys begin with the string AKIA

*To disable*
aws iam update-access-key --access-key-id AKIA... --status Inactive

re-enable
aws iam update-access-key --access-key-id AKIA... --status Active

*To delete*
aws iam delete-access-key --access-key-id AKIA


Session Keys ID begins with ASIA and are generated by AWS STS (Security Token Service)
* cannot be deleted or disabled like the long-term keys*

You can obtain information from the long-term key (AKIA) using the following command
Command: aws sts get-access-key-info --access-key-id AKIA********************
